🌦 Weather Forecast Application

A responsive Weather Forecast Application built using HTML, CSS, and JavaScript. It allows users to search for any city and view its current weather conditions along with a 5-day weather forecast.

✨ Features

- Search weather by city name
- Display current temperature
- Show weather conditions with icons
- Display humidity
- Show wind speed
- Display feels-like temperature
- 5-day weather forecast
- Responsive user interface
- Real-time weather data

🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API
- Open-Meteo Geocoding API

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "weather.html" in your web browser.
4. Enter a city name in the search box.
5. Click the Search button.

📁 Project Structure

Weather-Forecast/
│
└── weather.html

🌐 API Used

"Open-Meteo" (https://open-meteo.com/)

No API key is required.

🎯 Project Objective

The objective of this project is to provide users with an easy way to check current weather conditions and upcoming weather forecasts for different cities.
